# CampusHub

CampusHub is a simple campus event management website. It allows students to discover upcoming events, search and filter events, create new events, and view event details.

## Features

- View upcoming campus events
- Search for events
- Filter events by category
- Create new events
- View individual event details
- Register for events
- Save created events using localStorage
- Responsive design

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- localStorage
